# pdxsock v1.2.0 -- release manifest (source form)
#
# This is the human-readable source form of `manifest.pdxsig`. The
# release tool at pkgs.paideia-os mirror-push time (a) enumerates the
# artifact list below, (b) recomputes every BLAKE3-256 hash from the
# repo tree at the v1.2.0 tag, (c) writes the completed manifest into
# a binary `manifest.pdxsig`, and (d) invokes
#   paideia-pq-sign::sign_release_artifact(sk, manifest_path)
# once with the paideia-release-line Ed25519 secret key and once with
# the ML-DSA-65 secret key. The two detached signatures are appended
# to the manifest in the fixed layout below and the resulting
# `manifest.pdxsig` is pushed to
#   https://pkgs.paideia-os/main/pdxsock/1.2.0/manifest.pdxsig
# alongside the compiled artifacts.
#
# Format mirrors `mkfs.pdxfs`'s and `umount.pdxfs`'s own
# `release/manifest.pdxsig.txt` byte-for-byte in structure -- see
# either for the worked template this one follows. Every
# `<BLAKE3-*>` / `<...-KID-*>` / `<...-SIG-*>` slot below is a
# placeholder the release tool fills in from the working tree at
# tag time; NONE are computed by this milestone (see
# `release/RELEASE-1.2.0.md` §3 for why signing is out of scope
# here).
#
# v1.2.0 is the M5-001 dual-signed follow-on to v1.1.0 (unsigned
# source-tag release, 2026-09-08). No source file was added, removed,
# or edited between v1.1.0 and v1.2.0 -- the delta is release
# scaffolding only (this file, `release/RELEASE-1.2.0.md`,
# `doc/pdxsock.pdxdoc`, the CHANGELOG.md `[1.2.0]` stanza, and the
# manifest.pdxproj `version = 1.2.0` bump). Every `[artifacts.source]`
# hash below is therefore identical to the (never-materialised)
# hash-set a v1.1.0-signed manifest would carry.
#
# Reference:
#   design/paideia-as/v0.20-issue-1025-pq-signing.md         -- Hybrid,
#     sign_release_artifact, HybridSignature (Ed25519 || ML-DSA-65).
#   design/02-development-environment.md §1140                -- hybrid
#     release-artifact signature rationale (Ed25519 + ML-DSA-65).
#   design/tooling/plan.md §6.3                               -- package
#     repository layout, `manifest.pdxsig` per version directory.
#   design/networking/r100-user-tools-plan.md §7 + §13.6      -- pdxsock
#     scope + the 18-issue milestone breakdown this closes M5-001 of.
